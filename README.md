# 프로젝트 일정 관리

종합광고기획사용 일정 역산 도구. **행사일만 입력하면 표준 공정을 거꾸로 계산해 산출물별 작업 일정과 최종 검수일을 뽑아줍니다.**

HTML 파일 하나로 동작합니다. 설치도, 빌드도, 서버도 없습니다. `index.html`을 내려받아 더블클릭하면 끝입니다.

---

## 왜 만들었나

행사 하나에는 현수막, 리플렛, 홍보영상, 무대 운영이 딸려 옵니다. 각각 리드타임이 다른데, 머릿속으로 "인쇄 발주가 5일 걸리니까 검수는 늦어도…"를 매번 계산하면 반드시 하나는 놓칩니다.

이 도구는 그 역산을 대신합니다. 그리고 **일정이 물리적으로 불가능할 때 압축해서 숨기지 않고, 며칠이 부족한지 명시합니다.**

## 무엇을 하나

- **행사일에서 전체 공정 역산** — 마지막 단계(납품·현장 셋업·업로드)가 행사일에 끝나도록 모든 단계를 거꾸로 배치
- **산출물마다 다른 최종 검수일** — 인쇄물은 발주 리드타임만큼 앞서고, 행사 운영은 셋업·진행을 빼면 행사일 −3영업일
- **영업일 기준 계산** — 주말, 한국 공휴일(대체공휴일 포함), 회사 자체 휴무일 제외
- **다가오는 검수일 대시보드** — D-day 순 정렬, D-3 이내 빨강 배지
- **일정 부족 경고** — 표준 공정이 안 들어가면 부족한 영업일 수를 그대로 표시 (자동 압축 안 함)
- **자유 텍스트 입력** — 메모를 붙여넣으면 프로젝트·유형·행사일·산출물을 추출 (Claude API, 선택)
- **확정 후에도 편집** — 단계 추가/삭제, 소요일 변경, 날짜 고정 시 앞뒤 단계 연쇄 재계산

## 표준 공정 템플릿

| 산출물 | 공정 |
|---|---|
| **인쇄물** | 기획/카피 → 1차 시안 → 내부 검수 → 클라이언트 컨펌 → 수정 → **최종 검수** → 인쇄 발주 → 납품 |
| **영상** | 기획/콘티 → 촬영 → 편집 1차 → 검수 → 수정 → **최종본 확정** → 업로드 |
| **온라인/SNS 광고** | 전략 수립 → 소재 제작 → 내부 검수 → 클라이언트 컨펌 → 수정 → **최종 검수** → 매체 세팅 → 집행 시작 |
| **행사 운영** | 기획안 → 견적/발주 → 협력사 확정 → 리허설 준비 → **최종 점검** → 현장 셋업 → 행사 진행 |

단계별 기본 소요일은 설정 탭에서 회사 실정에 맞게 바꿀 수 있고, 프로젝트마다 개별 조정도 됩니다.

## 사용법

1. `index.html`을 내려받아 브라우저로 엽니다.
2. **＋ 텍스트로 프로젝트 넣기** 를 누릅니다.
3. 자유롭게 적거나, 아래 양식으로 적습니다:

   ```
   청주 문화의달 | 문화기획 | 2026-10-15 | 현수막, 리플렛, 홍보영상
   옥천 군민의날 | 지역행사 | 2026-11-03 | 무대 운영, 포스터
   ```

   양식은 `프로젝트명 | 유형 | 행사일 | 산출물들` 입니다. 유형은 `문화기획` / `지역행사` / `마케팅 캠페인`.
4. **양식으로 분석** (API 키 불필요) 또는 **AI로 분석** 을 누르고, 결과를 확인한 뒤 확정합니다.

### AI 분석 (선택)

자유 서술을 파싱하려면 설정 탭에 [Anthropic API 키](https://console.anthropic.com/)를 넣으세요. 키는 **브라우저 localStorage에만** 저장되며 Anthropic API 외 어디로도 전송되지 않습니다. 키 없이도 「양식으로 분석」은 그대로 동작합니다.

## 데이터

브라우저 localStorage에 저장됩니다. 서버도, 로그인도, 외부 전송도 없습니다. 백업이나 다른 PC로 옮기려면 설정 탭의 **JSON 내보내기 / 불러오기** 를 쓰세요.

브라우저 데이터를 지우면 프로젝트도 함께 지워집니다. 중요한 일정은 주기적으로 내보내 두세요.

## 공휴일

2026–2027년 한국 공휴일이 대체공휴일까지 포함해 하드코딩돼 있습니다 (`NATIONAL_HOLIDAYS`). 연 1회 갱신이 필요합니다. 창립기념일·워크숍 같은 회사 자체 휴무일은 설정 탭에서 추가하세요.

## 알려진 한계

- **AI 분석 경로는 실제 API 호출로 검증되지 않았습니다.** 브라우저에서 직접 호출하므로 환경에 따라 CORS 문제가 있을 수 있습니다. 그때는 「양식으로 분석」을 쓰세요.
- 팀 협업, 권한, 알림(브라우저·이메일), 간트차트, 달력 뷰는 범위 밖입니다. 단일 사용자용입니다.
- 공휴일 자동 갱신 없음 (공공데이터포털 API 미연동).

## 개발

의존성 없는 단일 HTML 파일입니다. 편집 후 브라우저에서 새로고침하면 끝입니다.

일정 계산 로직은 순수 함수로 분리돼 있어 Node로 직접 테스트할 수 있습니다 — `<script>` 블록에서 렌더링 이전 부분만 잘라 `new Function`으로 평가하면 `addBiz` / `subBiz` / `scheduleDeliverable` / `warningsFor` 등을 그대로 검증할 수 있습니다.
